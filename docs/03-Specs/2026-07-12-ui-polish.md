# Spec: UI 打磨 —— 视觉系统统一与"贴纸"签名

> **状态**：已批准
> **日期**：2026-07-12
> **来源需求**：用户反馈（2026-07-12）："网站有点粗糙"。[../01-Requirements/Backlog.md](../01-Requirements/Backlog.md)

## 1. 背景与目标

2026-07-12 全页面截图审查（桌面 1440 + 移动 390）发现的"粗糙"点：

1. 全站用 emoji 当图标（🖼🗂✂️💡），观感像未完成的模板。
2. 原生表单控件（range / checkbox / color）为浏览器默认灰蓝色，与紫色主题违和。
3. 去背景面板「自动取色」按钮文字折行成两行；取色行布局拥挤。
4. 按钮 / chip / 圆角 / 阴影风格混杂（pill、rounded-md、rounded-lg 并存），无统一组件。
5. 批量、拆分页空状态：一个虚线框漂在整页空白中，缺乏引导。
6. 首页卡片下方大片空白；语言切换（黑色块 + 裸文本）观感突兀。
7. 移动端导航可横滚但无任何可滚动暗示，看起来像缺项。
8. 上传解码 / 自动去背景期间无任何加载反馈。

**目标**：统一视觉系统 + 给品牌一个可记忆的签名，让站点看起来是"有人设计过的"，行为与信息架构不变。

## 2. 设计方向（frontend-design 结论）

- **主题（signature）**：**刻切贴纸（die-cut sticker）**。产品的输出就是白描边贴纸、产品的画布就是透明棋盘格——把这两种"自家物料"用在品牌时刻：
  - Logo 标：小圆角方块贴纸（棋盘格底 + 白描边 + 轻微倾斜 + 软阴影），旁置文字标。
  - 首页工作流卡片：图标以"贴纸"形式呈现（白边 + 微倾斜），hover 时轻微上浮回正（贴纸被揭起的感觉）。
  - 上传空状态图标同款贴纸处理。
  - 除以上品牌时刻外全站保持克制，不到处贴。
- **色板**（延续现有品牌紫，不换色）：
  - `primary` 紫 violet-600 `#7C3AED`（hover 700）
  - 中性 ink zinc-900 / muted zinc-500 / 边框 zinc-200 / 页面底 zinc-50
  - 语义色沿用：成功/隐私 emerald、警告 amber、危险 red
- **字体**：**不引入外部字体**（隐私承诺 = 零外部请求；中文 webfont 体积也不可接受）。系统栈 + 刻意的字重/字距层级；"Sticker Studio" 文字标用重字重 + 收紧字距。
- **控件**：统一组件层（见 §3）；range / checkbox 用 `accent-color` 染成主题紫（成本最低且原生可访问性保留）。
- **图标**：手写内联 SVG 图标集（stroke 风格，约 12-16 个），**不加依赖**。
- **动效**：仅 hover 微交互（卡片上浮、按钮 transition-colors）+ 处理中 spinner；全部尊重 `prefers-reduced-motion`。

## 3. 范围与决策表

| # | 决策点 | 结论 |
|---|---|---|
| D1 | 设计 tokens | Tailwind v4 `@theme`（index.css）定义语义色/圆角/阴影别名；组件类统一 控件=rounded-lg、卡片=rounded-2xl |
| D2 | 共享组件层 | 新建 `src/components/`：`Icon`、`Button`（primary/secondary/ghost/danger）、`Chip`（单选/多选 toggle）、`Panel`（卡片+标题）、`Spinner`；各 feature 逐步替换 |
| D3 | 图标 | 手写 SVG，无新依赖 |
| D4 | 加载反馈 | 上传解码 + 自动去背景期间：dropzone/画布显示 Spinner；导出/ZIP 按钮加 busy 态（需 store 暴露状态则补 flag + 红测试） |
| D5 | 移动端 | 导航保持横滚 + 渐隐遮罩暗示；面板/工具栏间距与折行修正；不做汉堡菜单 |
| D6 | 暗色模式 | **不做**（进 Backlog） |
| D7 | 文案 | 仅新增少量 i18n key（格式提示、加载中等），不重写现有文案 |
| D8 | 依赖 | 零新增 |

**非目标**：信息架构调整、换主色/品牌名、暗色模式、新功能、重写文案、图标库依赖。

## 4. 验收标准

1. 三件套（lint / typecheck / test）全绿 + `npm run build` 通过；现有测试不破。
2. 全站无 emoji 图标、无浏览器默认蓝控件（Playwright 截图目检：5 页 × 桌面/移动）。
3. 「自动取色」按钮单行显示；语言切换为统一分段控件。
4. 上传大图期间可见加载反馈；导出/ZIP 按钮处理中不可重复点击。
5. 隐私回归：全流程零外部网络请求（无字体/图标 CDN）。
6. 既有端到端流程（上传→导出透明 PNG、批量 ZIP、拆分 ZIP）Playwright 复测通过。
